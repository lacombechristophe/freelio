Pour reproduire dans une copie sans `.env`, avec Node 24 et dépendances déjà installées : définir une **nouvelle URL SQLite fictive**, `AUTH_SECRET` et `ENCRYPTION_KEY`, puis préparer cette base avec `npm run db:prepare:dev`. Exécuter `npm run test:unit -- tests/unit/communication-dashboard.integration.test.ts tests/unit/mailbox-access.integration.test.ts tests/unit/incoming-attachment.integration.test.ts tests/unit/member-mailbox-offboarding.integration.test.ts tests/unit/email-drafts.integration.test.ts`, puis types, les deux lints, suite complète et build. Les scripts UI exigent leur recette isolée ; ne pas les lancer sur des données existantes.
